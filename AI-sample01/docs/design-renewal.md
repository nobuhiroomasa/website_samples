# 宿福CMSサイト デザイン改善・JS演出追加依頼

## 目的

現在作成済みの宿福CMS型Webサイトを、より美しく、プロの店舗サイトのような見た目に改善する。

CMS機能や管理画面の基本機能は維持しつつ、公開側のデザイン・動き・写真の見せ方を大幅に改善する。

## 重要方針

既存のCMS機能は壊さないこと。

特に以下は維持する。

* 管理者ログイン
* 管理画面
* お知らせ管理
* 客室管理
* ギャラリー管理
* 画像アップロード
* お問い合わせフォーム

今回の作業は主に公開側ページのUI/UX改善とする。

## JavaScriptで追加したい演出

### 1. ファーストビュー演出

トップページ表示時に、メインビジュアルを美しく表示する。

実装例：

* 画像のフェードイン
* キャッチコピーのふわっと表示
* 背景画像のゆっくりズーム
* スクロール案内の表示

重すぎる演出にはしない。

### 2. スクロールアニメーション

ページをスクロールした時に、各セクションが自然に表示されるようにする。

実装例：

* 下からふわっと表示
* 画像が少し遅れて表示
* テキストが順番に表示
* カードが段階的に表示

Intersection Observer API を使用して実装する。

### 3. ヘッダー改善

スクロールに応じてヘッダーの見た目を変更する。

実装例：

* ファーストビュー上では透明ヘッダー
* スクロール後に背景色を付ける
* スマホではハンバーガーメニューを表示
* メニュー開閉時は背景を暗くする

### 4. 画像ギャラリー改善

ギャラリーページを写真が映えるUIにする。

実装例：

* グリッドレイアウト
* 画像ホバー時に少し拡大
* クリック時にモーダル表示
* カテゴリ絞り込み
* スマホでも見やすい配置

### 5. 客室カード改善

客室一覧をカード型で美しく表示する。

実装例：

* 写真を大きく表示
* 部屋名を重ねて表示
* ホバー時に詳細ボタン表示
* 定員・設備をアイコン風に表示

### 6. お知らせ表示改善

お知らせ一覧をシンプルで見やすくする。

実装例：

* カード型表示
* 日付を見やすく表示
* サムネイル画像表示
* ホバー時のアニメーション

### 7. ローディング演出

トップページ初回表示時に簡単なローディング演出を追加する。

例：

* SHUKUFUKU の文字表示
* 短いフェードアウト
* 長すぎないこと
* 1秒前後で終わること

## 使用技術

現在のLaravel構成を前提とする。

使用してよいもの：

* Blade
* CSS
* JavaScript
* Vite
* Tailwind CSS または Bootstrap
* Intersection Observer API
* CSS animation
* 必要であればSwiper.js

ただし、ライブラリを追加する場合は理由をコメントに残す。

## 実装ルール

* 既存のCMS機能を壊さない
* Bladeテンプレートを整理する
* 共通レイアウトを活用する
* CSSは可能な限り整理する
* JavaScriptは読みやすく分割する
* スマホ表示を必ず確認する
* PCとスマホの両方で美しく見えるようにする
* 画像がない場合でもレイアウトが崩れないようにする
