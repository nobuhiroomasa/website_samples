# 宿福CMS 管理画面の使い方

## 概要

このシステムの管理画面は、宿福 SHUKUFUKU の公開サイト内容を更新するためのCMSです。

公開側で変更できる主な対象:

- サイト基本情報
- トップページの文言と画像
- 各公開ページの見出し、導入文、ページ画像
- 客室情報
- お知らせ
- イベント
- ギャラリー
- お問い合わせ一覧
- SEO設定

## ログインURL

通常の `/login` は使いません。

管理画面ログインURL:

- `/owner-login`

例:

- `http://127.0.0.1:8000/owner-login`

## 初期ログイン情報

Seeder 実行直後の初期管理者アカウントは以下です。

- メールアドレス: `owner@example.com`
- パスワード: `password`

## 起動方法

### 1. 初期セットアップ

```bash
composer install
npm install
php artisan migrate:fresh --seed
php artisan storage:link
```

### 2. 開発サーバー起動

別ターミナルで以下を実行します。

```bash
php artisan serve --port=8000
```

```bash
npm run dev
```

本番ビルド確認だけしたい場合:

```bash
npm run build
```

## ログイン後の画面

ログイン後は以下へ遷移します。

- `/owner/dashboard`

ダッシュボードでは以下を確認できます。

- 客室件数
- お知らせ件数
- イベント件数
- ギャラリー件数
- 最新のお問い合わせ

## 管理画面メニュー

### サイト設定

URL:

- `/owner/settings`

ここで更新できる内容:

- サイトタイトル
- キャッチコピー
- 説明文
- 電話番号
- 住所
- SNSリンク
- トップページ文言
- 各ページの見出し、導入文、ページ画像
- カフェ昼夜の文言と画像
- アクセス情報
- お問い合わせページ文言
- 各ページのSEO title / meta description / OGP画像

保存すると公開サイトに反映されます。

## 画像アップロードについて

- アップロード画像は Laravel Storage を使います
- 公開表示には `php artisan storage:link` が必要です
- 画像未設定でもレイアウトは崩れにくい設計です

## よくある操作

### トップページのメイン画像を変える

1. 管理画面にログイン
2. `サイト設定` を開く
3. `トップページ表示設定` の `ヒーロー画像` を変更
4. 保存

### 客室を追加する

1. `客室管理` を開く
2. `客室を追加` を押す
3. 必要項目を入力
4. 保存

### ギャラリー写真を追加する

1. `ギャラリー管理` を開く
2. `写真を追加` を押す
3. カテゴリ、説明、画像を入力
4. 保存

### SEOを変更する

1. `サイト設定` を開く
2. 画面下部の `SEO設定` へ移動
3. ページごとの title / meta description / OGP画像を更新
4. 保存

## 注意事項

- 管理画面へ入れるのは `is_admin = true` のユーザーのみです
- `/owner-login` 以外の通常ログイン画面は使いません
- 公開 / 非公開の設定をオフにしたデータは公開側に出ません
- 開発環境で表示が崩れた場合は、`npm run dev` または `npm run build` を確認してください

## 動作確認コマンド

```bash
php artisan test
```

## 補足

初期データを作り直したい場合:

```bash
php artisan migrate:fresh --seed
```

このコマンドを実行すると、既存データはすべて消えます。
