# 認証機能仕様書

## 目的
Laravelアプリにログイン機能を追加し、items の作成・編集・削除をログインユーザーのみに制限する。

## 使用方針
- Laravel Breeze の Blade 版を使って認証機能を追加する
- ログイン、ユーザー登録、ログアウトができるようにする
- items の一覧・詳細は未ログインでも閲覧可能にする
- items の作成・編集・削除はログインユーザーのみ可能にする

## 権限方針
- item 作成時は user_id にログインユーザーのIDを保存する
- item の編集・削除は作成者本人のみ可能にする
- 他人の item を編集・削除しようとした場合は 403 エラーにする
- 未ログインで作成・編集・削除画面にアクセスした場合はログイン画面へリダイレクトする

## ルーティング方針
- GET /items は誰でもアクセス可能
- GET /items/{item} は誰でもアクセス可能
- GET /items/create はログイン必須
- POST /items はログイン必須
- GET /items/{item}/edit はログイン必須かつ作成者のみ
- PUT/PATCH /items/{item} はログイン必須かつ作成者のみ
- DELETE /items/{item} はログイン必須かつ作成者のみ

## DB方針
- items.user_id にログインユーザーのIDを保存する
- user_id は users.id を参照する
- 既存の user_id が null のデータはそのまま残してよい
- 今後作成される item は user_id を必須扱いにする

## 画面表示方針
- ログイン中はヘッダーにユーザー名とログアウトボタンを表示する
- 未ログイン時はログイン・新規登録リンクを表示する
- items 一覧・詳細では、作成者本人の場合のみ編集・削除ボタンを表示する
- 未ログイン時は作成ボタンを表示しない、またはログイン案内を表示する

## テスト方針
- 未ログインでも items 一覧を表示できる
- 未ログインでも items 詳細を表示できる
- 未ログインでは items 作成画面にアクセスできない
- ログインユーザーは item を作成できる
- item 作成時に user_id が保存される
- 作成者本人は item を編集できる
- 作成者本人は item を削除できる
- 他人の item は編集できない
- 他人の item は削除できない
