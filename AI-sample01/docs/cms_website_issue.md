# 宿福 SHUKUFUKU 公式サイト リニューアル開発依頼

## プロジェクト概要

大阪市都島区にあるゲストハウス「宿福 SHUKUFUKU」の公式サイトを全面リニューアルする。

現在サイトは情報掲載が中心になっているため、

「ここに泊まりたい」
「ここで過ごしてみたい」

と思える体験価値を伝えるサイトへ改善する。

## デザイン方針

旅館サイトではなく、

「泊まれる古民家コミュニティ」

を感じられるデザインにする。

写真を大きく使う。

文字量は減らし、
体験価値が伝わるUIを採用する。

## 完了条件

管理者がログインし、

* 写真変更
* 部屋情報変更
* イベント追加
* お知らせ追加
* ギャラリー追加

をコード編集なしで行えること。

一般ユーザーは宿福の魅力を直感的に理解できること。
