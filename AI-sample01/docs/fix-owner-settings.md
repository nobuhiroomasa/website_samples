# 宿福CMS 不具合修正依頼

## 対象

Laravelで作成している宿福CMSサイト。

## 修正してほしい不具合

### 1. 管理画面で画像が保存されない

#### 現象

管理画面から画像ファイルをアップロードして設定を保存しても、画像が保持されない。

特に `/owner/settings` のサイト設定編集画面で発生している。

#### 確認してほしいこと

以下を重点的に確認して修正してください。

* formタグに `enctype="multipart/form-data"` が設定されているか
* input type="file" の `name` と Controller 側の取得名が一致しているか
* Controller で画像ファイルを正しく保存できているか
* `storage/app/public` 配下に保存されているか
* DBに画像パスが保存されているか
* 更新時に画像未選択の場合、既存画像パスが消えないようになっているか
* `php artisan storage:link` 前提のパスになっているか
* バリデーションで画像が弾かれていないか

#### 期待する動作

* 管理画面で画像をアップロードして保存すると、画像パスがDBに保存される
* 保存後、編集画面に戻っても画像が保持されている
* 公開側ページにも設定した画像が反映される
* 画像を再アップロードした場合は新しい画像に更新される
* 画像を選択せずに他項目だけ更新した場合、既存画像は消えない

---

### 2. `/owner/settings` の横メニューバーをスクロール追従にする

#### 現象

管理画面の `/owner/settings` にある横のメニューバーが、ページスクロール時についてこない。

#### 修正内容

管理画面のサイドメニューをスクロール時も画面内に固定表示されるようにしてください。

#### 期待する動作

* PC表示ではサイドメニューがスクロールに追従する
* 長い設定画面をスクロールしても、左側メニューから別ページへ移動しやすい
* スマホ表示ではレイアウトが崩れない
* 既存の管理画面デザインを大きく壊さない

#### 実装方針

可能であれば CSS の `position: sticky` を使用してください。

例：

```css
.owner-sidebar {
    position: sticky;
    top: 24px;
    align-self: flex-start;
}
```

ただし、親要素の `overflow` 指定によって sticky が効かない場合があるため、その点も確認してください。

---

## 注意点

* 既存のCMS機能を壊さないこと
* 公開側ページに影響が出ないようにすること
* 修正後、画像アップロードと設定保存の動作確認を行うこと
* 管理画面のスマホ表示も確認すること

## 完了条件

以下を満たせば完了。

* `/owner/settings` で画像をアップロードして保存できる
* 保存後も画像が消えずに保持される
* 公開側ページに画像が反映される
* 画像未選択で保存しても既存画像が消えない
* `/owner/settings` のサイドメニューがスクロールに追従する
* PC・スマホ表示でレイアウト崩れがない
