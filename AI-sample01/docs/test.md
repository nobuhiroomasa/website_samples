# docs/test.md

## 確認項目

### 画面表示
- トップページが表示される
- 一覧ページが表示される
- 詳細ページが表示される
- 未ログインでは作成ページにアクセスするとログイン画面へ遷移する
- 作成者本人は編集ページを表示できる

### 登録処理
- ログインユーザーは正しい入力で登録できる
- 必須項目が空の場合、エラーになる
- 登録後に一覧ページへ遷移する
- 登録後にフラッシュメッセージが表示される
- 登録時に `user_id` が保存される

### 編集処理
- 作成者本人は登録済みデータを編集できる
- 不正な入力の場合、エラーになる
- 更新後に詳細ページへ遷移する
- 他人のデータを編集しようとすると 403 エラーになる

### 削除処理
- 作成者本人はデータを削除できる
- 削除後に一覧ページへ遷移する
- 削除後にフラッシュメッセージが表示される
- 他人のデータを削除しようとすると 403 エラーになる

### DB確認
- migration が正常に実行できる
- 必要なテーブルが作成される
- リレーションが正しく動く

### コマンド確認
```bash
composer install
npm install
php artisan migrate
php artisan db:seed
npm run dev
php artisan serve
php artisan test
```
